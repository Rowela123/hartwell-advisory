# Hartwell Advisory

A clean, responsive static consulting website for GitHub Pages.

## Edit the website

- Open `index.html` to change all written content, links, email addresses and project details.
- Open `styles.css` to change colours, spacing, typography and responsive styling.
- The main colours are listed at the top of `styles.css` under `:root`.
- Double-click `index.html` to preview the site locally in a browser.

## Upload to GitHub

1. Extract this ZIP.
2. Open the `hartwell-advisory` repository on GitHub.
3. Select **Add file → Upload files**.
4. Upload `index.html`, `styles.css` and `README.md` into the repository root.
5. Commit the files to the `main` branch.

## Enable GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Select **Save**.

GitHub will display the live website address after deployment finishes.
